### 标书排雷：售前经理的“减负”计划

在售前工作中，标书分析往往是耗时最长且最容易遗漏细节的环节。动辄几百页的招标文件，包含着大量的技术指标、合规要求与潜在的“排雷”点。

为了提升售前效率，我计划构建一套基于 **Dify** 的售前经理 AI Skill 工具库。本文将分享该项目的设计理念与技术实现。

### 1. 为什么选择 Agent 工具库？

标书分析的痛点在于“非结构化数据”与“动态标准”。不同行业、不同项目、不同客户的排雷规则完全不同，普通的搜索引擎或通用 LLM 无法处理复杂的规则约束。

我们需要的是一套可定制的 Agent 体系：
- **竞品分析**：自动提取招标文件中的关键需求，对比已有产品优势。
- **标书排雷**：基于规则库，动态识别招标文件中的敏感排他条款。
- **配置报价**：根据需求自动匹配推荐方案。

### 2. 技术架构设计

整个系统的核心在于**“数据前置处理 + Dify 智能编排”**。

#### 第一阶段：标书脱水 (Data Dehydration)
全量投喂 PDF 给 LLM 是极低效的。我设计了一个基于 Python 的前置处理流程：
- **提取与降维**：使用 `pymupdf` 提取文本，移除页眉页脚及冗余法律模板。
- **结构化归一**：将分散的表格和条款转化为语义清晰的 Markdown 结构。
- **Token 节约**：只保留关键技术要求与限制条款，剔除 50% 以上无关字符，显著降低 LLM 压力，提升 RAG 检索准确度。

#### 第二阶段：基于 Dify 的动态排雷
Dify 提供了理想的 Workflow 与知识库分组能力：
- **动态标准配置**：行业标准与规则以参数形式输入。
- **动态 Prompt**：Agent 根据当前“行业 + 场景 + 客户风格”标签，动态加载对应的排雷标准库。

### 3. 未来的扩展：社交生态发布
商业计划的最后一步是公域传播。利用 Dify 的 API，我们将排雷后的合规知识点，自动摘要并脱敏，分发至小红书或抖音，构建售前经理的专业个人 IP。

### 总结
该项目不仅是售前工作的“减负工具”，更是将售前经理的经验规则化、自动化的一次尝试。通过这种方式，我们能将更多时间投入到客户沟通中，而非繁琐的文档处理。
