在实验环境，我们关注准确率；在生产环境，我们关注『Agent 健康度』。将 Agent 视为一个服务，我们需要建立一套运营维度。

### 1. 响应质量指标
- **首字延迟 (TTFT)**：直接影响用户感知的流畅度。
- **上下文一致性**：长对话中 Agent 是否发生"遗忘"或"幻觉漂移"。

### 2. 系统稳定性
- **Tool 调用失败率**：API 的稳定性往往是 Agent 失败的主因。
- **异常逻辑覆盖率**：Agent 在面临无效输入时的 fallback 机制是否可靠。

### 3. 运营维度
- **人机介入率 (HITL)**：Agent 完成任务时，用户需要手动调整的比例。
- **反馈偏差率**：用户通过反馈修正 Agent 决策的频率。

生产级 Agent 运营的核心，在于将 AI 的运行状态指标化、看板化。只有被监控的系统，才真正具备在生产环境长期生存的能力。
