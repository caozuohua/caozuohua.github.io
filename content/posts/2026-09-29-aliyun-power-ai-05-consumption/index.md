# 阿里云电力 AI 调研（六）：用电侧——落地最扎实，责任边界最模糊

> 本系列共八篇，逐环节拆解阿里云在电力行业「发、输、变、配、用」的 AI 与 Agent 落地现状。
> 全部结论标注信源等级：**A** 官方（阿里云/客户官网、官方技术博客）、**B** 权威媒体 / 行业白皮书 / 信通院、**C** 厂商 PR 稿或会议演讲、**D** 二手转载（仅作线索）。
> 本系列刻意区分「已投产」与「方案宣传」，并对厂商口径保留独立判断。

## 一、用电侧的结构性变化

发电侧是少数大主体，用电侧是数亿分散主体。分布式光伏、电动汽车与可调负荷让用户第一次同时具备发电、储能与响应能力；市场化改革又把电价拆成分时、分区信号。电网营销与计量专业因此从「抄表计费」升级为「能源感知与客户互动中枢」——南方电网一次梳理出 **27 项「AI+计量」应用场景**（A/B）。

用电侧也是全系列唯一直接面对终端用户、牵涉真金白银的一环：计量误差影响结算，账单解释影响信任，电价建议影响支出。决策链末端站的是人——落地最扎实，责任边界也最模糊。

## 二、逐场景拆解

### 2.1 计量设备智能运维：广东电网「计量大脑」

**背景**：广东电网计量自动化系统覆盖全省**超 5000 万用户/智能电表**（A/B；两个口径并列）。单次异常从发现到派单传统需 **3 天**，故障成因多靠经验判断，数据不出内网。

**方案**：广东电网**计量系统 3.0** 上的「**计量设备 AI 指挥官**」，含 AI 巡视 / AI 检验（一作 AI 诊断）/ AI 运维 / AI 日报四个智能体；模型层为**多模态模型 + DeepSeek-R1 + MOE 专家模型 + 时序大模型**（A/B）。技术栈归因存分歧：**阿里云口径归于「通义千问」，南网口径归于「大瓦特 + DeepSeek-R1」**（B）。

**技术路径**（拼合报道，属推测）：

```text
采集层  智能电表 + 边缘计算节点（自动抄表率 99.6%）
平台层  大瓦特 / 通义千问 + MOE + 时序大模型
智能体  AI 巡视 → AI 诊断 → AI 运维（隐性挂号 / 显性急诊）→ AI 日报
执行层  精准派单 → 易联办公 eLink
```

**收益**：广东韶关供电局 **2025 年**运行「AI 诊断 + 精准派单」，单次异常处置从 3 天压到 **17 分钟**，工单处置效率提升 **8 倍**，**故障自愈率 80%**，AI 巡视计划有效性 **+30%**（A/B）。网级计量中心电量预测超 **97%**、分布式光伏预测 **90% 以上**、计量运维质检准确率 **90%**，已发快报 **340 余期**（A/B）。

**局限**：①「故障自愈率 80%」口径不清，未说明指远程自动复电还是仅指「自动诊断并派单」，若为后者则「自愈」有夸大嫌疑；②另有「处置效率提升 **80%**」一说（B+），与「8 倍」相差一个量级，并列不取平均；③跨省算法复用需等 2026 年启动的「网级智能计量能力共享平台」。

### 2.2 客户服务与电费账单解读：朗新「电力账单解读智能助手」

用户问「电费为什么这么高」，传统链路要客服 → 计费 → 后台三岗协同、等二次回复，易升级为投诉。方案为阿里云**百炼** + **通义千问**，2023 年朗新入选首批 7 家「通义千问伙伴」（A）。

四阶段后训练 **PT → SFT → RM → RLHF**；工程细节含**智能问数场景的 NL2SQL 微调**、plugin 参数 API 增强、**账单场景 Prompt 优化与多轮对话 SFT 微调**（A）。

朗新科技集团股份有限公司（300682.SZ）2023-08 接入百炼 → 2023-09 完成 POC → 2023 云栖大会发布。**官方原文限定「测试场景下」**：交互效率提高 **超 50%**、人工工单量下降 **超 70%**（A）。媒体版「投诉率降低超 70%」属派生演绎，不应引用（C）。局限是收益均带「测试环境」限定。

### 2.3 智能问数（NL2SQL）：朗新九功与阿里云数据分析机器人

电力企业沉淀了营销、采集、计量、交易多套系统的数据，业务人员不会写 SQL。阿里云官网「能源智能解决方案」列出「**数据分析机器人：基于 NL2SQL 技术挖掘数据价值**」，配国家电网最佳实践（A）。代表落地是朗新九功数据智能体，路径为自研 **Schema Linking 框架** + 层级式数据治理 + 思维链强化学习训练 SQL 生成（B）。

**2025-07 该产品获 BIRD-Bench 执行准确率（EX）与查询效率奖励（R-VES）双榜全球第一**，基准含 37 个行业场景、33GB、超 1 万条高复杂度查询（B）。边界见第三节。

### 2.4 用电侧负荷预测：达摩院八观气象大模型 + eForecaster

源荷双波动加剧后，气象同时影响发电（光伏、风电）与用电（居民、空调负荷）。痛点是节假日、极端天气等小样本场景传统方法失灵，现货需高频更新，调度需可解释性。方案为达摩院**可信时序预测平台 eForecaster**（内置可解释 AI）+ **八观气象大模型**（2024-11-06 发布，时空精度最高 1km×1km×1h）+ **敏迭 MindOpt Solver 2.0**（A/B）。

平台自 **2021-10 起**在山东等**七省**部署，获 **IAAI-23 创新应用奖**（B）。国网山东电力调控中心覆盖 **262 座风电场、331 座光伏电站**，新能源功率预测 **96%+**、负荷预测 **98%+**。国网嘉兴电力使用后，分布式光伏功率预测考核合格率 **+12.5%**、风电场 **+31.5%**（B）。

局限：各案例的「98%」定义不同（母线负荷 / 系统负荷 / 新能源功率 / 考核合格率），跨案例比较无意义；获奖不等于规模化收益，准确率提升对应的消纳或成本节约缺公开量化；「极端天气 AI 优于专家」是厂商口径且缺第三方验证；模型对未见工况（OOD）的鲁棒性会显著退化。

### 2.5 虚拟电厂与需求响应：AIVPP

中国最大用电负荷仅约发电装机容量的 50%。方案为 **AIVPP**，2023-10-31 云栖大会发布，阿里云首个云上虚拟电厂方案；商业化产品「虚拟电厂运营管理平台」可开通光储协同优化下的 3 类算法——用电负荷预测、新能源功率预测、储能运行优化策略（A）。

案例：阿里深圳园区单日单建筑可调 **>1.3MW**、空调能耗降 12%；红狮控股集团云边协同 VPP 平台使**企业电费整体降低 5%**；阿里 20+ 园区参与需求响应，动态聚合达 **130% 响应量**（C）。

### 2.6 综合能源与双碳：能耗宝（Energy Expert）

方案为 2021 年推出、2022-06-30 全球发布的 SaaS **能耗宝**，功能三块——能耗管理和优化 / 碳排计算 / 减碳方案，支持 MQTT、Modbus 采集，联合莱茵 TÜV、中国赛宝等 10 余家机构认证（A）。案例：杭州华聚复合材料**年节电 17 万度、减碳 120+ 吨**；另有皖能长丰生态科技园、杭州亚运村等案例（A）。

局限：碳核算「合法但不唯一」，因子库与边界认定会显著改变结果，存在漂绿空间；平台整体口径（如「日节电超 200 万千瓦时」）易被误读为单一客户成效。

### 2.7 充电桩与车网互动：星星充电、中国石化

万帮数字能源（星星充电）在阿里云全球数据中心基础上构建分布式充电平台（中心云 + 边缘云 IoT），基于 MaxCompute、Flink、Hologres 等建离线 + 实时数仓（A/B）。收益：约 **26 万个**充电桩在线（后续口径 **39.9 万台**公共桩）；采集频率从 **90 秒提升到 17 秒**。中国石化累计建成充换电站**超 8400 座**、覆盖 370 个城市、年自营充电量破 **10 亿度**，全部跑在阿里云上（B）。

局限：**未找到阿里云主导的 V2G 双向充放电公开落地案例**；可确认的仅是其与几省电网交易中心、VPP 平台对接及微电网低谷响应探索。**「充电桩上云」不等于「V2G 落地」。**

### 2.8 电力市场交易服务

三条线并行：① 朗新购售电一体化平台 + **九功电力交易智能体**（动态多智能体协同、7×24 在线，日前电价预测 **>90%**、价差方向 >75%、风险预警 **>85%**）；② **南方区域电力市场高可靠电力调度云平台**（南方电网联合阿里云，飞天企业版专有云，超 3500 节点、支撑 200+ 套核心系统，2019 年上线）（A/B）。

收益：朗新 2025 年交易电量**超 60 亿度**（为上年的 3 倍）；国网上海电力联合 16 家数据中心算电协同，2 小时内最大压减负荷 9.78 万千瓦；南方区域电力市场调度云告警量减少 **90%**（B/D）。局限：交易电量口径混乱（见 5.2）；「>90%」未说明是 MAPE、命中率还是方向判断，而现货交易中「方向判断 75%」更接近真实盈利门槛；告警量 -90% 是运维效果，与交易收益无关。

- **BIRD**（脏数据、隐式业务逻辑、外部知识）：约 **65–73%**；
- **Spider 2.0**（真实企业工作流、多库、**1000+ 列**）：约 **21%**；
- **LLM 直连客户真实 Schema**（不做工程增强）：**10–20%**。

91% 与 21% 之间有**70 个百分点的悬崖**，这正是多数 pilot 在第二个月翻车的根因。学术实测更悲观：ESQ-Bench（465 表、4 种方言）中 GPT-4o 的 EX 仅 **79.8% / 60.3% / 57.2%**，而**静默语义偏差在 EX 通过的查询中高达 73–99%**——「SQL 跑通了但结果是错的」是常态（B）。

朗新的双榜冠军因此要这样读：BIRD-Bench 是公开基准，表结构复杂度仍低于电力生产库，**冠军不等于真实库上的生产准确率**。朗新自己也强调用 Schema Linking + 数据治理 + 思维链 RL 来「修补」，恰印证裸模型不够用。工程侧对策是 Schema 索引 + 执行前 SQL 校验层 + 人工在环审核，可把准确率带回 86–95%，代价是「自动化」变成「半自动化」。

一句话：**榜单冠军 ≠ 生产可用。**

## 四、责任边界：AI 答错电费谁负责

电费账单解读与峰谷电价开通建议都属「价格」类事项。AI 一旦答错，已有三条规则明确：

1. **国标层面**：2025-09-01 起实施的推荐性国标《顾客联络服务 人工与智能客户服务协同要求》要求，涉及**价格、折扣、退款、赔偿、合同变更**等事项，AI 只能解释规则、收集材料、生成工单，**最终确认应由人工或规范化流程完成**（B）。
2. **消费者权益层面**：中国消费者协会与经济日报明确，**经营者不能以「算法自动生成」为由免责**（B）。
3. **法学层面**：华北电力大学新金融法学中心主任陈燕红指出，AI 答复错误可能构成服务瑕疵或违约，而**违约责任不以经营者主观过错为构成要件**（B）。

责任归属方向由此清楚：几乎必然落在经营者身上。但「归属清楚」不等于「机制成熟」——赔付标准、举证责任、合规边界，公开信息里都没有答案。更尖锐的是「推荐峰谷分时电价」：AI 建议会改变用户电费结构，若用户并不适合峰谷计价、因而多付费，损失谁承担？

一句话：**能力先落地了，责任机制还在后面追。**

## 五、需要泼冷水的部分

### 5.1 虚拟电厂：商业模式未跑通，官方文件自认

国家能源局/国家发改委《关于加快推进虚拟电厂发展的指导意见》（发改能源〔2025〕357 号）解读原文承认：市场主导模式（广东、云南）「**均处于试点阶段**」，补贴支撑模式（深圳）「依赖补贴资金起步」，「**部分虚拟电厂运营商还无法实现经营性业务盈亏平衡**」；且「缺乏有效的调节能力评估认定技术标准，**实际可调节能力不实**」（A）。行业实况更冷：全国注册 VPP 运营商超 430 家，**近一半没有实际业务，有的只是占了个壳**；烟台市公交集团案例中一度电平均调节收益约 **0.4 元**；能源基金会张永平判断「**调度煤电、独立储能电站等资源要比调度聚合用户侧资源的虚拟电厂更容易**」（B）。

因此阿里云 VPP 案例需拆读：**阿里自有园区是「自己给自己做」的样板**；红狮电费降 5% 是源网荷储协同收益、不纯为 VPP 收益；「130% 响应量」只是技术指标。

### 5.3 未找到公开信源的事项

以下三项明确**未找到**公开信源，不作推测：① 阿里云主导的 **V2G 双向充放电落地项目**；② 「**储能电站选址优化**」的客户与成效（官网仅列名）；③ 阿里云在**居民侧（户级）负荷预测**的独立案例。同理，朗新账单助手**只有测试环境数据**，广东计量大脑**无第三方评估报告**，虚拟电厂用 AIVPP 后**盈利的公开案例**也未找到。

### 5.4 竞品提示：「独家」叙事不成立

南方电网总调在 2023 年**同时与阿里、百度、华为签署电力调度 AI 合作备忘录**（B）。头部电网客户遵循「多头下注、不绑定单一厂商」，此外特来电采用多云、电享科技与阿里云共创 VPP、南网自研「大瓦特」。本系列不采用任何「独家」表述。

## 六、小结

用电侧是阿里云电力版图中**落地最扎实**的一环：计量运维、负荷预测、账单解读、能碳与充电运营五类都有可查的客户主体、时间线与量化数字；技术路径也一致——**大模型负责推理，专用模型/API 负责取数与计算，规则兜底，人最终确认**。

但它同时**责任边界最模糊**：计量误差影响结算，账单解释影响信任，电价建议影响支出，而 AI 一旦答错，赔付标准、举证责任与合规边界都无成熟机制。NL2SQL 的天花板（真实企业库约 21%、静默错误率 73–99%）说明，「说人话查数据」在真实库上远未到可无人值守。

留给总览与结语的三个判断：**（1）可复制性分层**——朗新模式较强（已 28 省售电），广东计量模式依赖南网总部统筹，中小电力企业难以照搬；**（2）数据边界**——电网核心营销/计量数据不出内网是硬红线；**（3）成本数据缺失**——国产 GPU 训推与微调成本，公开信源为零。
