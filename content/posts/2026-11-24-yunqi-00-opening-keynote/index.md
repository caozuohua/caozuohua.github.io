## 一、一分钟结论

1. **大会主题「智以致用」**，全场只锚定一件事：Agentic AI 从技术演示走向生产系统。阿里没有铺开讲应用故事，而是把 **模型、芯片、云** 三层基础设施一次性摊开。
2. **吴泳铭给出两个判断**：未来机器思考总量是人类的 **1000 倍以上**（今天不足 3%）；**机器智能时代的代表性产品至今没有出现**——今天的 AI Coding 只是「1882 年的电灯」。
3. **三大基石**：AI 模型、AI 芯片、AI 云。对应三张硬牌：**Qwen4 在训、目标 5–10T 参数**；**真武 V900（3 倍于 M890，单集群 50 万卡，2027 Q1 量产）**；**2032 年全球数据中心超 20GW**。
4. **最具冲击力的证据不是参数，而是闭环**：Qwen3.8-Max 仅凭一份芯片模块 spec，自主运行 **60+ 小时**、调用工业级 EDA 工具 **数万次**，完成前端到后端全链路，芯片面积缩减 **42%**——模型开始参与设计下一代芯片。
5. **云的重构**：李飞飞把 Agentic Cloud 拆成 **Model + Harness + Context**，云的价值从「运营算力」转向「运营智力」；AgentCore 把任务完成率做到 99%、TCO 降 70%。
6. **两个产业样本给出可验算的账**：荣耀手机 Agent 综合任务准确率 **91.8%**、端到端闭环 **>90%**；平安日均 Token 从 300 亿增至 3000 亿+，算力仅增不到 2 倍，单位 Token 成本降 **76%**。

## 三、全场主线：一条完整的因果链

整场论坛不是并列的八场演讲，而是一条被刻意编排的论证链：

```
判断层：机器成为思考主力 → 思考成为可规模化供给的商品
   ↓
瓶颈层：要供给思考，先要供给基础设施 → 三大基石（模型 / 芯片 / 云）
   ↓
能力层：模型会做事（Qwen）→ 芯片供得起（平头哥）→ 云接得住（Agentic Cloud）
   ↓
体验层：全模态生成把「想到」压缩为「看见」
   ↓
落地层：终端（荣耀）+ 行业（平安）交出可验算的账
   ↓
回到判断层：所以代表性产品还没出现，基础设施先行
```

这条链解释了为什么一位 CEO 会在自家产品发布会式的场合说「代表性产品还没有出现」——**这是一句为「建发电站」争取合法性的判断，而不是一句谦虚话**。

### 4.4 吴泳铭（阿里巴巴集团 CEO）主旨演讲《机器智能时代的战略选择》（27:10–46:30）

全场信息密度最高的一场。结构是「两个判断 → 三大基石 → 一个价值主张」。

#### 判断一：机器思考总量将是人类的 1000 倍以上

- 类比：工业革命把**动力**变成规模化商品（蒸汽机、内燃机、电），机器动力今天承担了世界 **99.9%** 的物理工作；
- 这一次轮到**思考**：AI 基础设施扩展后，思考像动力一样成为可规模化供给的商品；
- 今天机器思考总量**不足人类的 3%**，若未来是 1000 倍，则还有**几万倍**增长空间；
- 推演从供需两侧展开：
  - **供给**：顶级思考极其稀缺——培养一名顶级科学家需数十年学习实践加天赋运气；罕见病（如新生儿早衰症，全球每年新增仅几十例、有记录患者数百人）长期缺乏研究资源。当 AI 具备专业研究能力且算力足够便宜，**每个细分领域都可组织上百万个 Agent** 持续研究、模拟、验证。**「顶级思考将从奢侈品变成可规模化供给的商品。」**
  - **需求**：工业时代商品消费受人口上限约束（咖啡、车、手机）；AI 时代思考消耗不再与人口成正比，而与**思考深度和供给规模**成正比。火星飞船这类任务可拆成上万子任务、由上百万 Agent 不眠不休推进。**「每一个超级个体都可以拥有上万倍的智力杠杆。」**

#### 判断二：机器智能时代的代表性产品还没有出现

- 电最早只是替代煤油灯与蜡烛；1882 年爱迪生建成珍珠街电站，点亮约 **400 盏灯**，且最早卖灯泡是**送半年电**——「非常像今天下载一个 App 送一个月 token」；
- 真正改变世界的东西是后来才出现的：空调（1902）、洗衣机、电冰箱，第一台计算机要到 **1946 年**，距那 400 盏灯已过 60 多年；
- 所以：**今天的 AI Coding 就像机器智能时代早期的电灯**——替代的是人类现在能做的工（古法编程、写报告）；「仅仅替代现有的工作，不可能创造一个真正的新时代」；
- 但「无论后来出现多少新发明，第一步都是要建足够多的发电站、铺足够广的电网」——1900 年前后全球全年发电量，放到今天只够全世界用**两小时**。

#### 三大基石

**① AI 模型：通往 ASI 的路径是 RSI（递归式自我改进）**

- 路径定义：模型从真实反馈中发现自身短板 → 自己设计实验 → 自己构建数据 → 自己评价结果 → 循环推动进化；
- 千问团队已在 RSI 上取得进展，**计划训练 5–10T 参数规模的全新模型**，目标是完成更复杂、更长程的任务；
- 另一条主线是**理解与生成一体化的多模态**：「一个足够聪明的大脑还不够」——AI 要像人一样理解声音、图像、表情、动作，并对齐人类文化、审美与价值观；当 AI 能像人一样交流，人就不必再面对复杂交互界面。

**② AI 芯片：Token 是电，芯片是发电机**

- 平头哥已完成数据中心芯片全面布局：**真武**（GPU）、**倚天**（CPU）、**磐脉**（智能网卡）、**ICN**（互联芯片）；
- 自研 **M890 AI 超节点**已成功支撑**两万亿参数以上**大模型推理，「全球极少数具备这样能力的公司之一」，本季度起规模化上架；
- **发布真武 V900**：当前中国算力性能最强的 AI 芯片，性能达 M890 的 **3 倍**，单集群可扩展至 **50 万卡**；预计平头哥年出货量大幅提升；
- 智能走向终端：桌面端开源 **Qwen-27B**（全球最受开发者欢迎的模型之一，支持本地化部署）；移动端**正式发布 Qwen Intelligence**，为合作伙伴提供移动 AI 解决方案。

**③ AI 云：承载机器智能的超级电网**

- 目标体验是「插座式」：今天人很少注意电网，插上就有电；未来设备只要接入云，就能随时使用机器智能；
- 需要一张覆盖全球、高效运转的超级网络，对 GPU、CPU、网络、存储、数据库、工具做**联合优化**，形成规模效应与网络效应；
- 现实约束（全场最诚实的一句）：**客户需求非常强劲，但行业中長期需求远超供给能力，AI 数据中心相关供应链全球性紧缺，正在限制算力增长速度**；
- 承诺：**到 2032 年，阿里云运营的全球数据中心规模超过 20GW**。

#### 价值主张

- 工业革命把人类从体力劳动中解放后，诞生了足球、篮球、现代奥运会、世界杯、NBA；
- 印刷术带来文化创作爆发；照相机没有消灭绘画，反而催生印象派与抽象艺术；留声机没有让歌手失业，反而让音乐成为最广泛的大众艺术；
- 「当机器承担了更多不得不做的事情，人便有时间去做真正想做的事情」；
- 收束：「**把繁重的任务留给机器，把时间、创造力以及对美好事物的感受留给人类**」——延续去年「AI 越强大，人类更强大」。

### 4.5 刘大一恒（ATH 事业群 Token Foundry，Qwen LLM 项目负责人）《Qwen：迈向真实世界智能体》（47:05–64:05）

#### 三段论：Chatbot → Reasoning → Agentic

- Chatbot 时代：人提问、AI 答；
- Reasoning 时代：模型用更多 token 思考、推理、验证；
- **Agentic 时代（今年）**：模型不再是被动等候提问的助手，而是能自主规划、调用工具、持续迭代闭环完成任务的智能体；
- 关键变化在**消费形态**：AI 从「一次对话」变成「一项任务」，直接拉动全球 token 需求指数级爆发。

#### 北极星：两条腿走路

| 方向   | 含义                                 | 产品线                                     |
| ---- | ---------------------------------- | --------------------------------------- |
| 仰望星空 | 追求更高智能、加速自我进化，突破能力天花板              | Qwen-Max                                |
| 脚踏实地 | 追求极致性价比、推动 AI 普惠（成本不降，Agent 无法规模化） | Qwen-Flash / Qwen-Plus / Qwen-27B（本地部署） |

#### Roadmap 四个关键方向

**① 深入真实生产**

- **Qwen3.8-Max 相比 Qwen3.7，两个月内真实用户收入增长 8.5 倍，token 消耗量增长 12 倍**；

## 七、五个可复用的判断

1. **「基础设施先行」是这个阶段唯一正确的下注方向**。当代表性产品尚未出现时，能确定的需求只有基础设施。这不是保守，而是把不确定性转移到了确定性最高的一层。
2. **竞争单位已经从「芯片/模型」上移到「系统」**。高慧的三句话（推理优先、多步编排、系统协同）和李飞飞的 Model+Harness+Context 是同一个判断的两种表述：单点性能不再决定成败，**算存网协同效率** 才是。
3. **RSI 的第一个可验证产物不在榜单上，而在工程闭环里**。60 小时、数万次 EDA 调用、面积 −42% —— 这是「模型参与设计下一代芯片」的第一个可触摸证据，比任何跑分都更能支撑「自我改进」的叙事。
4. **成本曲线决定 Agent 能否规模化**。郑波说体验边际成本趋零，刘大一恒说成本不降 Agent 无法落地，李飞飞说 TCO 降 70%，王晓航给出 −76% 的实测——**四场演讲在同一个变量上收敛**。
5. **「按任务结果付费」可能是 AI 商业模式的拐点**。云从运营算力转向运营智力，意味着计费单位从「资源」变为「结果」，这会同时改写云厂商的毛利结构与企业的采购逻辑。
